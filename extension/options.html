    Fingerprint randomization

    Adds tiny, invisible noise to canvas, WebGL and audio readback on protected pages so they can't fingerprint your device. Turn this off if a drawing app, game or editor misbehaves while protection is on. Focus spoofing keeps working either way.

    Anonymous usage statistics

    Off by default. If you turn this on, Focus Spoofer sends one small summary per day with counts, which helps us see whether it actually works for people. No browsing history, URLs, site names, page content or identifiers are ever sent.

    Exactly what is sent
    • Extension version and the date (day only) the counts are for
    • How many times protection was turned on and off that day
    • How many Always-On sites were added or removed (not which ones), and whether you have any
    • Whether this was the first time protection was ever turned on
    • Counts of internal error types (e.g. "script registration failed"), never error messages

    There is no install ID, so reports can't be linked to each other or to you. Turning this off deletes anything not yet sent.
