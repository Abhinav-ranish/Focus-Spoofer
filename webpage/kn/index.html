03

ನಿಮ್ಮ ಸಾಧನವನ್ನು ಟ್ರ್ಯಾಕ್ ಮಾಡಲಾಗುತ್ತದೆ

ಇದಿಲ್ಲದೆ

ಕುಕೀಗಳಿಲ್ಲದಿದ್ದರೂ, ನಿಮ್ಮ ಸಾಧನ ಗ್ರಾಫಿಕ್ಸ್ ಚಿತ್ರಿಸುವ ರೀತಿಯಿಂದಲೇ ಸೈಟ್‌ಗಳು ಅದನ್ನು ಸದ್ದಿಲ್ಲದೆ ಗುರುತಿಸಬಲ್ಲವು.

Focus Spoofer ಜೊತೆ

ಅತಿ ಸಣ್ಣ ರ್ಯಾಂಡಮ್ ಬದಲಾವಣೆಗಳಿಂದ ಪ್ರತಿ ಭೇಟಿಯಲ್ಲೂ ನೀವು ಬೇರೆ ಸಾಧನದಂತೆ ಕಾಣುತ್ತೀರಿ. ಇದನ್ನು ಸೆಟ್ಟಿಂಗ್‌ಗಳಲ್ಲಿ ಆಫ್ ಮಾಡಬಹುದು.

ಹ್ಯಾಶ್ … ಹ್ಯಾಶ್ …
ಇಂಟರ್‌ಫೇಸ್

ಒಂದೇ ಸ್ವಿಚ್.
ಅಷ್ಟೇ ಇಂಟರ್‌ಫೇಸ್.

ನೀವಿರುವ ಟ್ಯಾಬ್‌ನಲ್ಲಿ ಇದನ್ನು ಆನ್ ಮಾಡಿ, ಅಥವಾ ಪ್ರತಿ ಭೇಟಿಯಲ್ಲೂ ಒಂದು ಸೈಟ್ ಅನ್ನು ರಕ್ಷಿತವಾಗಿಡಿ. ಉಳಿದೆಲ್ಲವೂ ಒಂದು ಸರಳ ಸೆಟ್ಟಿಂಗ್‌ಗಳ ಪುಟದಲ್ಲಿದೆ.

ನೇರ ಉತ್ತರಗಳು

ಇದು ಏನು ಮಾಡುವುದಿಲ್ಲ.

ಪ್ರಾಕ್ಟರಿಂಗ್ ಅಥವಾ ಆ್ಯಂಟಿ-ಚೀಟ್ ಅನ್ನು ಮೀರುವುದು.

ಪರೀಕ್ಷೆ ಮತ್ತು ಆ್ಯಂಟಿ-ಚೀಟ್ ಸಾಫ್ಟ್‌ವೇರ್‌ಗಳು ವೆಬ್ ಪುಟಕ್ಕಿಂತ ಎಷ್ಟೋ ಹೆಚ್ಚನ್ನು ಗಮನಿಸುತ್ತವೆ. ಅವುಗಳನ್ನು ತಪ್ಪಿಸಲು ನಾವು ಪ್ರಯತ್ನಿಸುವುದಿಲ್ಲ, ಅದಕ್ಕಾಗಿ ನೀವು ಇದನ್ನು ನಂಬಬಾರದು.

ಎಲ್ಲೆಡೆ ಕೆಲಸ ಮಾಡುವುದು.

ಇದು Chrome, Brave ಮತ್ತು Edge ನಲ್ಲಿ ಸಾಮಾನ್ಯ ವೆಬ್ ಪುಟಗಳಲ್ಲಿ ಕೆಲಸ ಮಾಡುತ್ತದೆ. chrome://, Web Store ಮತ್ತು ಅಂತರ್ನಿರ್ಮಿತ PDF ವೀಕ್ಷಕದಂತಹ ಬ್ರೌಸರ್ ಪುಟಗಳು ಯಾವುದೇ ಎಕ್ಸ್‌ಟೆನ್ಶನ್‌ಗೆ ನಿಷಿದ್ಧ.

ನಿಮ್ಮ ಬ್ರೌಸಿಂಗ್ ಸಂಗ್ರಹಿಸುವುದು.

ಖಾತೆ ಇಲ್ಲ, ಹಿಸ್ಟರಿ ಇಲ್ಲ, ಸೈಟ್‌ಗಳಿಲ್ಲ. ನೀವು ಒಪ್ಪದ ಹೊರತು ಬಳಕೆಯ ಅಂಕಿಅಂಶಗಳು ಆಫ್ ಆಗಿರುತ್ತವೆ, ಒಪ್ಪಿದರೂ ಅವು ಯಾವುದೇ ID ಇಲ್ಲದ ದೈನಂದಿನ ಎಣಿಕೆಗಳು ಮಾತ್ರ. ಗೌಪ್ಯತಾ ನೀತಿ.

ಪ್ರಶ್ನೆಗಳು

ಪದೇ ಪದೇ ಕೇಳುವ ಪ್ರಶ್ನೆಗಳು.

ನಾನು ಟ್ಯಾಬ್ ಬದಲಿಸಿದ್ದು ವೆಬ್‌ಸೈಟ್‌ಗೆ ತಿಳಿಯದಂತೆ ಮಾಡುವುದು ಹೇಗೆ?

Focus Spoofer ಇನ್‌ಸ್ಟಾಲ್ ಮಾಡಿ, ಸೈಟ್ ತೆರೆಯಿರಿ, ಎಕ್ಸ್‌ಟೆನ್ಶನ್ ಐಕಾನ್ ಕ್ಲಿಕ್ ಮಾಡಿ ಸ್ವಿಚ್ ಆನ್ ಮಾಡಿ. ರಕ್ಷಣೆ ಸಕ್ರಿಯವಾಗಿ ಟ್ಯಾಬ್ ರಿಲೋಡ್ ಆಗುತ್ತದೆ: document.hidden false ಆಗಿಯೇ ಇರುತ್ತದೆ, visibilitychange ಮತ್ತು ವಿಂಡೋ blur ಈವೆಂಟ್‌ಗಳು ಪುಟವನ್ನು ತಲುಪುವುದೇ ಇಲ್ಲ, ಮತ್ತು document.hasFocus() true ನೀಡುತ್ತದೆ. ಪ್ರತಿ ಭೇಟಿಯಲ್ಲೂ ಸೈಟ್ ರಕ್ಷಿಸಲು "ಈ ಸೈಟ್ ಅನ್ನು ಯಾವಾಗಲೂ ರಕ್ಷಿಸಿ" ಟಿಕ್ ಮಾಡಿ.

ಟ್ಯಾಬ್ ಬದಲಿಸಿದಾಗ ವಿಡಿಯೋ ಅಥವಾ ಉಪನ್ಯಾಸ ಏಕೆ ನಿಲ್ಲುತ್ತದೆ?

ಹಲವು ಪ್ಲೇಯರ್‌ಗಳು Page Visibility API ನ visibilitychange ಈವೆಂಟ್ ಅಥವಾ ವಿಂಡೋ blur ಈವೆಂಟ್‌ಗಾಗಿ ಕಾಯುತ್ತವೆ, ಟ್ಯಾಬ್ ಮರೆಯಾದ ಕೂಡಲೇ ನಿಲ್ಲುತ್ತವೆ. ಕೆಲವು, ಟ್ಯಾಬ್ ಹಿನ್ನೆಲೆಯಲ್ಲಿದ್ದಾಗ ಅನಿಮೇಶನ್ ಫ್ರೇಮ್‌ಗಳು ನಿಲ್ಲುವುದನ್ನೂ ಗಮನಿಸುತ್ತವೆ. Focus Spoofer ಈ ಮೂರಕ್ಕೂ ಉತ್ತರ ನೀಡುತ್ತದೆ, ಹಾಗಾಗಿ ಪ್ಲೇಯರ್ ನಡೆಯುತ್ತಲೇ ಇರುತ್ತದೆ.

ಟ್ಯಾಬ್ ಬದಲಿಸಿದಾಗ TikTok, Twitch ಅಥವಾ ಕೋರ್ಸ್ ವಿಡಿಯೋಗಳು ಏಕೆ ನಿಲ್ಲುತ್ತವೆ?

ಇಂತಹ ಸೈಟ್‌ಗಳು Page Visibility API ಮತ್ತು ವಿಂಡೋ blur ಈವೆಂಟ್ ಬಳಸಿ ತಮ್ಮ ಟ್ಯಾಬ್ ಇನ್ನೂ ಕಾಣುತ್ತಿದೆಯೇ, ಫೋಕಸ್‌ನಲ್ಲಿದೆಯೇ ಎಂದು ಪರಿಶೀಲಿಸುತ್ತವೆ; ಇಲ್ಲದಿದ್ದರೆ ಪ್ಲೇಬ್ಯಾಕ್ ನಿಲ್ಲಿಸುತ್ತವೆ ಅಥವಾ ಕಡಿಮೆ ಮಾಡುತ್ತವೆ. ಆ ಟ್ಯಾಬ್‌ನಲ್ಲಿ Focus Spoofer ಆನ್ ಮಾಡಿ, ಅಥವಾ “ಈ ಸೈಟ್ ಅನ್ನು ಯಾವಾಗಲೂ ರಕ್ಷಿಸಿ” ಟಿಕ್ ಮಾಡಿ. ಆಗ ಪುಟಕ್ಕೆ ಕಾಣುವ, ಫೋಕಸ್‌ನಲ್ಲಿರುವ ಟ್ಯಾಬ್ ಮಾತ್ರ ಕಾಣುತ್ತದೆ, ಹಾಗಾಗಿ ನೀವು ಬೇರೆ ಟ್ಯಾಬ್ ಅಥವಾ ವಿಂಡೋದಲ್ಲಿ ಕೆಲಸ ಮಾಡುವಾಗಲೂ ಪ್ಲೇಬ್ಯಾಕ್ ಮುಂದುವರಿಯುತ್ತದೆ.

Chrome ನಲ್ಲಿ Page Visibility API ಅನ್ನು ಆಫ್ ಮಾಡುವುದು ಹೇಗೆ?

Chrome ನಲ್ಲಿ ಇದಕ್ಕೆ ಯಾವುದೇ ಸೆಟ್ಟಿಂಗ್ ಇಲ್ಲ. ಸೈಟ್‌ನ ಸ್ವಂತ ಸ್ಕ್ರಿಪ್ಟ್‌ಗಳು ಓಡುವ ಮೊದಲೇ ಒಂದು ಎಕ್ಸ್‌ಟೆನ್ಶನ್ ಪುಟದೊಳಗೆ ಇದನ್ನು ಓವರ್‌ರೈಡ್ ಮಾಡಬೇಕು. Focus Spoofer ಇದನ್ನು document_start ನಲ್ಲಿ, ನೀವು ಆರಿಸಿದ ಟ್ಯಾಬ್ ಅಥವಾ ಸೈಟ್‌ಗಳಲ್ಲಿ ಮಾತ್ರ ಮಾಡುತ್ತದೆ, ಉಳಿದ ಟ್ಯಾಬ್‌ಗಳನ್ನು ಮುಟ್ಟುವುದಿಲ್ಲ.

Focus Spoofer ಉಚಿತವೇ, ಇದು ನನ್ನ ಡೇಟಾ ಸಂಗ್ರಹಿಸುತ್ತದೆಯೇ?

ಇದು ಉಚಿತ, ಖಾತೆ ಬೇಕಿಲ್ಲ. ನಿಮ್ಮ ಬ್ರೌಸಿಂಗ್ ಹಿಸ್ಟರಿ, ನೀವು ಭೇಟಿ ನೀಡುವ ಸೈಟ್‌ಗಳು ಮತ್ತು ಪುಟದ ವಿಷಯ ಎಂದಿಗೂ ನಿಮ್ಮ ಬ್ರೌಸರ್ ಬಿಟ್ಟು ಹೋಗುವುದಿಲ್ಲ. ಐಚ್ಛಿಕ ಅನಾಮಧೇಯ ಬಳಕೆಯ ಅಂಕಿಅಂಶಗಳು (ದೈನಂದಿನ ಎಣಿಕೆಗಳು, ಯಾವುದೇ ಗುರುತಿಲ್ಲ) ನೀವು ಆನ್ ಮಾಡದ ಹೊರತು ಆಫ್ ಆಗಿರುತ್ತವೆ. ವಿವರಗಳು ಗೌಪ್ಯತಾ ನೀತಿಯಲ್ಲಿವೆ.

ಇದು ಯಾವ ಬ್ರೌಸರ್‌ಗಳಲ್ಲಿ ಕೆಲಸ ಮಾಡುತ್ತದೆ?

Windows, macOS, Linux ಮತ್ತು ChromeOS ನಲ್ಲಿ Chrome, Brave ಮತ್ತು Microsoft Edge. ಇದು Chrome Web Store ನಿಂದ ಇನ್‌ಸ್ಟಾಲ್ ಮಾಡುವ Manifest V3 ಎಕ್ಸ್‌ಟೆನ್ಶನ್. Firefox ಮತ್ತು Safari ಗೆ ಬೆಂಬಲವಿಲ್ಲ.

ಇದು ಕೆಲಸ ಮಾಡುತ್ತಿದೆಯೇ ಎಂದು ಹೇಗೆ ಪರಿಶೀಲಿಸುವುದು?
