Straight answers

What it won't do.

Beat proctoring or anti-cheat.

Exam and anti-cheat software watch far more than a web page can. We don't try to get around them, and you shouldn't rely on this for that.

Run everywhere.

It works on regular web pages in Chrome, Brave and Edge. Browser pages like chrome://, the Web Store and the built-in PDF viewer are off limits to every extension.

Collect your browsing.

No account, no history, no sites. Usage stats are off unless you opt in, and even then they're daily counts with no ID. Privacy policy.

Questions

Frequently asked questions.

How do I stop a website from detecting that I switched tabs?

Install Focus Spoofer, open the site, click the extension icon and turn the switch on. The tab reloads with protection active: document.hidden stays false, visibilitychange and window blur events never reach the page, and document.hasFocus() returns true. To protect a site on every visit, tick "Always protect this site".

Why does a video or lecture pause when I switch tabs?

Many players listen for the Page Visibility API's visibilitychange event or the window blur event and pause as soon as the tab is hidden. Some also notice that animation frames stop while a tab is in the background. Focus Spoofer answers all three, so the player keeps going.

Why do TikTok, Twitch or course videos pause when I switch tabs?

Sites like these check whether their tab is still visible and focused, using the Page Visibility API and the window blur event, and pause or lower playback when it isn't. Turn Focus Spoofer on for that tab, or tick “Always protect this site”, and the page keeps seeing a visible, focused tab, so playback carries on while you work in another tab or window.

How do I disable the Page Visibility API in Chrome?

Chrome has no setting for it. An extension has to override it inside the page before the site's own scripts run. Focus Spoofer does this at document_start, only on the tabs or sites you choose, and leaves every other tab untouched.

Is Focus Spoofer free, and does it collect my data?

It is free, with no account. Your browsing history, the sites you visit and page content never leave your browser. Optional anonymous usage statistics (daily counts, no identifier) are off unless you turn them on. Details are in the privacy policy.

Which browsers does it work in?

Chrome, Brave and Microsoft Edge on Windows, macOS, Linux and ChromeOS. It is a Manifest V3 extension installed from the Chrome Web Store. Firefox and Safari are not supported.

How can I check that it's working?

Open the live tab-switch detection test, turn Focus Spoofer on for that tab, switch to another tab for a few seconds and come back. With protection on, the event log stays empty.

Will it get around exam proctoring or anti-cheat software?

No, and it isn't meant to. Proctoring and anti-cheat tools can watch far more than a web page sees, such as the whole screen, other processes or the camera. Focus Spoofer only changes what a page can learn through the Page Visibility API, focus events and frame timing.
