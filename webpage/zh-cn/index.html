常见问题

常见问题。

如何阻止网站检测到我切换了标签页？

安装 Focus Spoofer，打开目标网站，点击扩展程序图标并打开开关。标签页会重新加载并启用保护：document.hidden 始终为 false，visibilitychange 和窗口 blur 事件永远不会到达页面，document.hasFocus() 返回 true。如需每次访问都保护某个网站，勾选“始终保护此网站”即可。

为什么切换标签页时视频或网课会暂停？

很多播放器会监听 Page Visibility API 的 visibilitychange 事件或窗口的 blur 事件，标签页一被隐藏就暂停。有些播放器还会发现标签页在后台时动画帧停止了。Focus Spoofer 对这三种情况都做了处理，播放器就能继续播放。

为什么切换标签页时 TikTok、Twitch 或网课视频会暂停？

这类网站会通过 Page Visibility API 和窗口 blur 事件检查自己的标签页是否仍然可见且处于焦点，一旦不是，就暂停或降低播放质量。在该标签页上开启 Focus Spoofer，或勾选“始终保护此网站”，页面看到的就始终是一个可见且处于焦点的标签页，你在其他标签页或窗口中做事时，播放也不会中断。

如何在 Chrome 中禁用 Page Visibility API？

Chrome 没有相关设置，必须由扩展程序在网站自身脚本运行之前，在页面内将其覆盖。Focus Spoofer 在 document_start 阶段完成这一步，只作用于你选择的标签页或网站，其他标签页一概不动。

Focus Spoofer 免费吗？会收集我的数据吗？

完全免费，无需账号。你的浏览记录、访问的网站和页面内容永远不会离开浏览器。可选的匿名使用统计（每日计数，不含标识符）默认关闭，除非你主动开启。详情请见隐私政策。

支持哪些浏览器？

支持 Windows、macOS、Linux 和 ChromeOS 上的 Chrome、Brave 和 Microsoft Edge。它是一款 Manifest V3 扩展程序，从 Chrome Web Store 安装。不支持 Firefox 和 Safari。

如何确认它在正常工作？

打开标签页切换检测实时测试，在该标签页上开启 Focus Spoofer，切换到其他标签页几秒钟再切回来。开启保护后，事件日志会保持为空。

它能绕过考试监考或反作弊软件吗？

不能，它也不是为此设计的。监考和反作弊工具能监控的远超网页所见，比如整个屏幕、其他进程或摄像头。Focus Spoofer 只改变页面通过 Page Visibility API、焦点事件和帧时序所能获知的信息。
