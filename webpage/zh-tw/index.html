問題

常見問題。

如何讓網站偵測不到我切換分頁？

安裝 Focus Spoofer，打開網站，點擊擴充功能圖示並打開開關。分頁會重新載入並啟用保護：document.hidden 維持 false，visibilitychange 和視窗 blur 事件永遠不會傳到頁面，document.hasFocus() 則回傳 true。若要每次造訪都保護某個網站，請勾選「一律保護這個網站」。

為什麼切換分頁時影片或課程會暫停？

許多播放器會監聽 Page Visibility API 的 visibilitychange 事件或視窗的 blur 事件，分頁一被隱藏就暫停。有些還會察覺分頁在背景時動畫影格停止了。Focus Spoofer 三種都能應付，播放器就會繼續播放。

為什麼切換分頁時 TikTok、Twitch 或課程影片會暫停？

這類網站會透過 Page Visibility API 和視窗 blur 事件，檢查自己的分頁是否仍然可見且處於焦點；若不是，就暫停播放或降低畫質。在該分頁開啟 Focus Spoofer，或勾選「一律保護這個網站」，頁面看到的就永遠是可見且處於焦點的分頁，你在其他分頁或視窗工作時也能繼續播放。

如何在 Chrome 中停用 Page Visibility API？

Chrome 沒有這個設定。必須由擴充功能在網站自己的指令碼執行前，於頁面內覆寫它。Focus Spoofer 會在 document_start 時這麼做，只作用於你選擇的分頁或網站，其他分頁完全不受影響。

Focus Spoofer 免費嗎？會收集我的資料嗎？

完全免費，也不需要帳號。你的瀏覽紀錄、造訪的網站和頁面內容絕不會離開瀏覽器。選用的匿名使用統計（每日計數，不含識別碼）預設關閉，除非你主動開啟。詳情請見隱私權政策。

支援哪些瀏覽器？

支援 Windows、macOS、Linux 和 ChromeOS 上的 Chrome、Brave 與 Microsoft Edge。這是從 Chrome Web Store 安裝的 Manifest V3 擴充功能。不支援 Firefox 和 Safari。

怎麼確認它有沒有作用？

打開即時切換分頁偵測測試，在該分頁開啟 Focus Spoofer，切到其他分頁幾秒再回來。啟用保護時，事件紀錄會保持空白。

它能規避線上監考或反作弊軟體嗎？

不能，它也不是為此設計的。監考與反作弊工具能監看的遠比網頁多，例如整個螢幕、其他程序或攝影機。Focus Spoofer 只會改變網頁透過 Page Visibility API、焦點事件和影格時序所能得知的資訊。
