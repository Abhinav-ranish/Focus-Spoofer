Pertanyaan

Pertanyaan yang sering diajukan.

Bagaimana cara mencegah situs web mendeteksi bahwa saya pindah tab?

Pasang Focus Spoofer, buka situsnya, klik ikon ekstensi, lalu aktifkan tombolnya. Tab dimuat ulang dengan perlindungan aktif: document.hidden tetap false, event visibilitychange dan blur jendela tidak pernah sampai ke halaman, dan document.hasFocus() mengembalikan true. Untuk melindungi situs setiap kali berkunjung, centang "Selalu lindungi situs ini".

Mengapa video atau kuliah berhenti saat saya pindah tab?

Banyak pemutar mendengarkan event visibilitychange dari Page Visibility API atau event blur jendela, lalu berhenti begitu tab disembunyikan. Sebagian juga mendeteksi bahwa frame animasi berhenti saat tab berada di latar belakang. Focus Spoofer menangani ketiganya, sehingga pemutar tetap berjalan.

Mengapa video TikTok, Twitch, atau kursus berhenti saat saya pindah tab?

Situs seperti ini memeriksa apakah tabnya masih terlihat dan difokuskan, menggunakan Page Visibility API dan event blur jendela, lalu menjeda atau menurunkan pemutaran jika tidak. Aktifkan Focus Spoofer untuk tab itu, atau centang “Selalu lindungi situs ini”, dan halaman akan terus melihat tab yang terlihat dan difokuskan, sehingga pemutaran tetap berlanjut saat Anda bekerja di tab atau jendela lain.

Bagaimana cara menonaktifkan Page Visibility API di Chrome?

Chrome tidak punya setelan untuk itu. Sebuah ekstensi harus menimpanya di dalam halaman sebelum skrip situs berjalan. Focus Spoofer melakukannya pada document_start, hanya di tab atau situs yang Anda pilih, dan tidak menyentuh tab lainnya.

Apakah Focus Spoofer gratis, dan apakah ia mengumpulkan data saya?

Gratis, tanpa akun. Riwayat penjelajahan, situs yang Anda kunjungi, dan isi halaman tidak pernah meninggalkan browser Anda. Statistik penggunaan anonim opsional (hitungan harian, tanpa pengenal) tetap mati kecuali Anda mengaktifkannya. Detailnya ada di kebijakan privasi.

Di browser apa saja ekstensi ini berfungsi?

Chrome, Brave, dan Microsoft Edge di Windows, macOS, Linux, dan ChromeOS. Ini adalah ekstensi Manifest V3 yang dipasang dari Chrome Web Store. Firefox dan Safari tidak didukung.

Bagaimana cara memastikan ekstensi ini berfungsi?

Buka uji deteksi pindah tab langsung, aktifkan Focus Spoofer untuk tab itu, pindah ke tab lain selama beberapa detik, lalu kembali. Dengan perlindungan aktif, log event tetap kosong.

Apakah ekstensi ini bisa mengakali pengawas ujian atau perangkat lunak anti-cheat?

Tidak, dan memang tidak dibuat untuk itu. Alat pengawas ujian dan anti-cheat bisa memantau jauh lebih banyak daripada yang dilihat halaman web, seperti seluruh layar, proses lain, atau kamera. Focus Spoofer hanya mengubah apa yang bisa diketahui halaman melalui Page Visibility API, event fokus, dan waktu frame.
