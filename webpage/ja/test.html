このページは、追跡サイトと同じ方法でタブの切り替えを検知します。visibilitychange とウィンドウの blur を監視し、document.hasFocus() を定期的に確認し、canvas、WebGL、音声の出力をハッシュ化します。いったん離れて戻ってくると何が検知されたかがわかります。次は Focus Spoofer をオンにして試してください。

イベントログ
フォーカステスト
  1. ツールバーから、このタブで Focus Spoofer をオンにします。
  2. 別のタブに切り替えるか、ウィンドウを最小化して数秒待ちます。
  3. 戻ってきます。ログに blur や visibility の記録がなければ、正しく動作しています。
フィンガープリント テスト
  1. 拡張機能をオフにした状態で、何度か再読み込みします。3つのハッシュは同じままです。
  2. オンにしてもう一度再読み込みします。ハッシュが読み込みのたびに変わります。
  3. 設定でフィンガープリントのランダム化をオフにしている場合は、仕様どおり同じままです。

各チェックの意味

チェック項目保護なしでタブを切り替えた後Focus Spoofer ありの場合
visibilitychange / document.hiddenログに 表示状態: hidden、続いて visible と表示記録なし。hidden は false のまま
ウィンドウの blur / focusログに ウィンドウのフォーカスが外れました、続いて ウィンドウにフォーカスしました と表示記録なし
document.hasFocus()離れている間は false常に true
Canvas、WebGL、音声のハッシュ再読み込みしても同じ値（固定のフィンガープリント）再読み込みのたびに変化（設定でフィンガープリントのランダム化をオフにしている場合を除く）

サーバー側でのアクティビティのタイミングなど、どのブラウザ拡張機能でもすべてのサイトから隠しきれないシグナルもあります。Focus Spoofer が対応する範囲としない範囲については、よくある質問をご覧ください。
