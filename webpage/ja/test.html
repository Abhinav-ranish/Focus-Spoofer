イベントログ
フォーカステスト
  1. ツールバーから、このタブで Focus Spoofer をオンにします。
  2. 別のタブに切り替えるか、ウィンドウを最小化して数秒待ちます。
  3. 戻ってきます。ログに blur や visibility の記録がなければ、正しく動作しています。
フィンガープリント テスト
  1. 拡張機能をオフにした状態で、何度か再読み込みします。3つのハッシュは同じままです。
  2. オンにしてもう一度再読み込みします。ハッシュが読み込みのたびに変わります。
  3. 設定でフィンガープリントのランダム化をオフにしている場合は、仕様どおり同じままです。

各チェックの意味

チェック項目保護なしでタブを切り替えた後Focus Spoofer ありの場合
visibilitychange / document.hiddenログに 表示状態: hidden、続いて visible と表示記録なし。hidden は false のまま
ウィンドウの blur / focusログに ウィンドウのフォーカスが外れました、続いて ウィンドウにフォーカスしました と表示記録なし
document.hasFocus()離れている間は false常に true
Canvas、WebGL、音声のハッシュ再読み込みしても同じ値（固定のフィンガープリント）再読み込みのたびに変化（設定でフィンガープリントのランダム化をオフにしている場合を除く）

この結果の意味は？

サーバー側でのアクティビティのタイミングなど、どのブラウザ拡張機能でもすべてのサイトから隠しきれないシグナルもあります。Focus Spoofer が対応する範囲としない範囲については、よくある質問をご覧ください。

各シグナルの仕組みについて詳しく：Page Visibility API、バックグラウンドタブの requestAnimationFrame、バックグラウンドタブのスロットリング。

ページから見えること

シグナルきっかけわかることわからないこと
visibilitychange / document.hiddenタブの切り替え、ウィンドウの最小化タブが非表示になったことと、その時間どのタブやアプリに移ったか
ウィンドウの blur / focus別のウィンドウ、アプリ、モニターのクリック、タブの切り替えページがフォーカスを失ったことと、戻ったタイミングページが画面に表示されたままだったか
document.hasFocus()ページがいつでも問い合わせられるイベントを見逃していても、今フォーカスがあるかどうか2 回の問い合わせの間に起きたこと
requestAnimationFrame のタイミング非表示のタブはフレームの描画を止める表示状態のイベントがブロックされていても、フレーム時刻の空白表示はされているがフォーカスのないウィンドウ（フレームは動き続けるため）

どんな表示状態スプーファーもテストできます

使うツールが Always Active Window でも Focus Spoofer でも、document.hidden を書き換えるユーザースクリプトでも、テストのやり方は同じです。このタブでツールをオンにして再読み込みしてください。

  • タブを切り替えて戻ります。ログが空なら、表示状態と blur の両方がブロックされています。
  • このウィンドウを別のウィンドウの横に並べ、そちらをクリックします。document.hasFocus() は true のままのはずです。
  • ログに表示状態の記録がなく ウィンドウのフォーカスが外れました だけが出る場合、ツールはタブの切り替えは隠せても、フォーカスの変化は隠せていません。

よくある質問

タブを切り替えると、サイトにわかりますか？

はい。どのページも document.hidden を読み取り、visibilitychange やウィンドウの blur を監視できます。許可を求める必要もありません。ただし、どのタブやアプリに移ったかはわかりません。

ログに blur はあるのに、表示状態の変化がないのはなぜ？

このタブを画面に表示したまま、別のウィンドウやアプリに移ったためです。blur はページがフォーカスを失うたびに発生します。表示状態の変化は、タブの切り替えや最小化など、タブが非表示になったときだけ発生します。

Focus Spoofer をオンにしてもハッシュが変わらないのはなぜ？

設定でフィンガープリントのランダム化がオフになっている可能性があります。オンのときはページを読み込むたびにハッシュが変わるので、再読み込みすると新しい値が表示されます。

結果はどこかに送信されますか？

いいえ。チェックはブラウザ内で実行され、ログとハッシュはこのタブの中だけに残ります。
