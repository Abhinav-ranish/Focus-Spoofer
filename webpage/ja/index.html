よくある質問

よくある質問。

タブを切り替えたことをウェブサイトに検知させないには？

Focus Spoofer をインストールしてサイトを開き、拡張機能のアイコンをクリックしてスイッチをオンにします。タブが再読み込みされ、保護が有効になります。document.hidden は false のまま、visibilitychange とウィンドウの blur イベントはページに届かず、document.hasFocus() は true を返します。サイトを毎回保護するには、「このサイトを常に保護」にチェックを入れます。

タブを切り替えると動画や講義が一時停止するのはなぜ？

多くのプレーヤーは Page Visibility API の visibilitychange イベントやウィンドウの blur イベントを監視していて、タブが非表示になるとすぐに一時停止します。タブがバックグラウンドにあるとアニメーション フレームが止まることを検知するものもあります。Focus Spoofer はこの3つすべてに対応するので、プレーヤーは再生を続けます。

TikTok、Twitch、講座の動画がタブ切り替えで止まるのはなぜ？

こうしたサイトは Page Visibility API とウィンドウの blur イベントを使って、自分のタブがまだ表示されていてフォーカスがあるかを確認し、そうでなければ再生を一時停止したり画質を下げたりします。そのタブで Focus Spoofer をオンにするか、「このサイトを常に保護」にチェックを入れると、ページからは表示中でフォーカスのあるタブに見え続けるので、別のタブやウィンドウで作業している間も再生が続きます。

Chrome で Page Visibility API を無効にするには？

Chrome にはそのための設定はありません。拡張機能が、サイト自身のスクリプトが実行される前にページ内で上書きする必要があります。Focus Spoofer は document_start の時点でこれを行います。対象は選んだタブやサイトだけで、ほかのタブには一切手を加えません。

Focus Spoofer は無料？データは収集される？

無料で、アカウントも不要です。閲覧履歴、アクセスしたサイト、ページの内容がブラウザの外に出ることはありません。オプションの匿名使用統計（1日ごとの回数、識別子なし）は、オンにしない限りオフです。詳しくはプライバシー ポリシーをご覧ください。

どのブラウザで使えますか？

Windows、macOS、Linux、ChromeOS の Chrome、Brave、Microsoft Edge で使えます。Chrome Web Store からインストールする Manifest V3 の拡張機能です。Firefox と Safari には対応していません。

動作しているか確認するには？

タブ切り替え検知のライブテストを開いてそのタブで Focus Spoofer をオンにし、数秒間別のタブに切り替えてから戻ってきてください。保護が有効なら、イベントログは空のままです。

試験監視やアンチチートソフトを回避できますか？

いいえ。そのためのものではありません。試験監視やアンチチートのツールは、画面全体、ほかのプロセス、カメラなど、ウェブページから見える範囲よりはるかに多くを監視できます。Focus Spoofer が変えるのは、ページが Page Visibility API、フォーカスイベント、フレームのタイミングから知りうる情報だけです。
