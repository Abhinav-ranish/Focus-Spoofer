ടാബ് മാറുന്നത് സൈറ്റിന് കാണാമോ? Page Visibility API ടെസ്റ്റ്

ഈ ടാബിനെ
ആരെങ്കിലും നിരീക്ഷിക്കുന്നുണ്ടോ?

അതെ. നിങ്ങൾ ടാബോ വിൻഡോയോ മാറുന്നത് ഏതു പേജിനും visibilitychange, വിൻഡോ blur, document.hasFocus() എന്നിവ വഴി അറിയാം, ഈ പേജ് അതേ പരിശോധനകൾ ലൈവായി നടത്തുന്നു: മാറിപ്പോയി തിരികെ വരൂ, പിടികൂടിയത് ലോഗിൽ കാണാം.

ഫോക്കസ് ടെസ്റ്റ്
  1. ടൂൾബാറിൽ നിന്ന് ഈ ടാബിൽ Focus Spoofer ഓൺ ചെയ്യുക.
  2. കുറച്ച് സെക്കൻഡ് മറ്റൊരു ടാബിലേക്ക് മാറുക, അല്ലെങ്കിൽ വിൻഡോ മിനിമൈസ് ചെയ്യുക.
  3. തിരികെ വരിക. ലോഗിൽ blur, visibility എൻട്രികൾ ഇല്ലെങ്കിൽ ഇത് പ്രവർത്തിക്കുന്നു എന്നർത്ഥം.
ഫിംഗർപ്രിന്റ് ടെസ്റ്റ്
  1. എക്സ്റ്റൻഷൻ ഓഫ് ആക്കി കുറച്ച് തവണ റീലോഡ് ചെയ്യുക. മൂന്ന് ഹാഷുകളും മാറില്ല.
  2. ഓൺ ചെയ്ത് വീണ്ടും റീലോഡ് ചെയ്യുക. ഇപ്പോൾ ഹാഷുകൾ ഓരോ ലോഡിലും മാറും.
  3. ക്രമീകരണങ്ങളിൽ ഫിംഗർപ്രിന്റ് റാൻഡമൈസേഷൻ ഓഫ് ചെയ്തോ? എങ്കിൽ അവ മാറില്ല, അത് മനഃപൂർവമാണ്.

ഓരോ പരിശോധനയുടെയും അർത്ഥം

പരിശോധനസംരക്ഷണമില്ലാതെ, ടാബ് മാറിയശേഷംFocus Spoofer-നൊപ്പം
visibilitychange / document.hiddenലോഗിൽ Visibility: hidden, പിന്നെ visible കാണിക്കുംഎൻട്രികളില്ല; hidden false ആയി തുടരും
വിൻഡോ blur / focusലോഗിൽ വിൻഡോ ഫോക്കസ് നഷ്ടമായി, പിന്നെ വിൻഡോ ഫോക്കസിൽ കാണിക്കുംഎൻട്രികളില്ല
document.hasFocus()നിങ്ങൾ മാറിനിൽക്കുമ്പോൾ falseഎപ്പോഴും true
Canvas, WebGL, ഓഡിയോ ഹാഷ്ഓരോ റീലോഡിലും ഒരേ മൂല്യം (സ്ഥിരമായ ഫിംഗർപ്രിന്റ്)ക്രമീകരണങ്ങളിൽ ഫിംഗർപ്രിന്റ് റാൻഡമൈസേഷൻ ഓഫ് അല്ലെങ്കിൽ, ഓരോ റീലോഡിലും മാറും

ഈ ഫലങ്ങളുടെ അർത്ഥമെന്ത്?

സെർവർ-സൈഡ് ആക്ടിവിറ്റി ടൈമിംഗ് പോലെ, ഒരു ബ്രൗസർ എക്സ്റ്റൻഷനും എല്ലാ സൈറ്റുകളിൽ നിന്നും മറയ്ക്കാനാവാത്ത മറ്റ് സൂചനകളുമുണ്ട്. Focus Spoofer എന്തൊക്കെ മറയ്ക്കുന്നു, എന്തൊക്കെ ഇല്ല എന്നറിയാൻ FAQ കാണുക.

ഓരോ സൂചനയും എങ്ങനെ പ്രവർത്തിക്കുന്നു എന്നതിനെക്കുറിച്ച് കൂടുതൽ: Page Visibility API, പശ്ചാത്തല ടാബുകളിലെ requestAnimationFrame, പശ്ചാത്തല ടാബ് ത്രോട്ടിലിംഗ്.

ഒരു പേജിന് എന്തൊക്കെ കാണാം

സൂചനഎപ്പോൾ സംഭവിക്കുന്നുഎന്ത് വെളിപ്പെടുത്തുന്നുഎന്ത് കാണാനാവില്ല
visibilitychange / document.hiddenടാബ് മാറൽ, വിൻഡോ മിനിമൈസ് ചെയ്യൽടാബ് മറഞ്ഞിരുന്നു എന്നതും എത്ര നേരമെന്നതുംനിങ്ങൾ ഏത് ടാബിലേക്കോ ആപ്പിലേക്കോ പോയി എന്ന്
വിൻഡോ blur / focusമറ്റൊരു വിൻഡോ, ആപ്പ്, മോണിറ്റർ ക്ലിക്ക്; ടാബ് മാറൽപേജിന് ഫോക്കസ് പോയതും എപ്പോൾ തിരികെ കിട്ടിയെന്നതുംപേജ് അപ്പോഴും സ്ക്രീനിലുണ്ടായിരുന്നോ എന്ന്
document.hasFocus()പേജ് ഇഷ്ടമുള്ളപ്പോൾ ചോദിക്കുന്നുഇപ്പോൾ പേജിന് ഫോക്കസുണ്ടോ എന്ന്, ഇവന്റ് നഷ്ടമായാലുംരണ്ട് പരിശോധനകൾക്കിടയിൽ നടന്നത്
requestAnimationFrame ടൈമിംഗ്മറഞ്ഞ ടാബുകൾ ഫ്രെയിം വരയ്ക്കുന്നത് നിർത്തുന്നുഫ്രെയിം സമയങ്ങളിലെ വിടവ്, visibility ഇവന്റുകൾ തടഞ്ഞാലുംകാണാവുന്നതും എന്നാൽ ഫോക്കസില്ലാത്തതുമായ വിൻഡോ, ഫ്രെയിമുകൾ തുടരുന്നതിനാൽ

ഏത് visibility സ്പൂഫറും പരിശോധിക്കൂ

ഏത് ടൂൾ ഉപയോഗിച്ചാലും ടെസ്റ്റ് ഒരുപോലെ പ്രവർത്തിക്കും: Always Active Window, Focus Spoofer, അല്ലെങ്കിൽ document.hidden മാറ്റുന്ന ഒരു userscript. ഈ ടാബിനായി ടൂൾ ഓണാക്കി റീലോഡ് ചെയ്യൂ.

  • ടാബ് മാറി തിരികെ വരൂ. ലോഗ് ശൂന്യമാണെങ്കിൽ visibility-യും blur-ഉം രണ്ടും തടഞ്ഞിരിക്കുന്നു.
  • ഈ വിൻഡോ മറ്റൊന്നിന്റെ അരികിൽ വെച്ച് മറ്റേതിൽ ക്ലിക്ക് ചെയ്യൂ. document.hasFocus() true ആയിത്തന്നെ തുടരണം.
  • ലോഗിൽ വിൻഡോ ഫോക്കസ് നഷ്ടമായി ഉണ്ടെങ്കിലും visibility എൻട്രികൾ ഇല്ലെങ്കിൽ, ടൂൾ ടാബ് മാറ്റം മറയ്ക്കുന്നു, ഫോക്കസ് മാറ്റം മറയ്ക്കുന്നില്ല.

ചോദ്യങ്ങൾ

ഞാൻ ടാബ് മാറുന്നത് വെബ്സൈറ്റുകൾക്ക് കാണാനാകുമോ?

അതെ. ഏതു പേജിനും അനുമതി ചോദിക്കാതെ document.hidden വായിക്കാനും visibilitychange, വിൻഡോ blur എന്നിവ കേൾക്കാനും കഴിയും. നിങ്ങൾ ഏത് ടാബിലേക്കോ ആപ്പിലേക്കോ പോയി എന്ന് അതിന് കാണാനാവില്ല.

ലോഗിൽ blur ഉണ്ട്, പക്ഷേ visibility മാറ്റം എന്തുകൊണ്ട് ഇല്ല?

ഈ ടാബ് സ്ക്രീനിൽ ഉള്ളപ്പോൾ നിങ്ങൾ മറ്റൊരു വിൻഡോയിലേക്കോ ആപ്പിലേക്കോ പോയി. പേജിന് ഫോക്കസ് നഷ്ടമാകുമ്പോഴെല്ലാം blur സംഭവിക്കും. ടാബ് മറയുമ്പോൾ മാത്രമാണ് visibility മാറ്റം, ഉദാഹരണത്തിന് ടാബ് മാറുമ്പോഴോ മിനിമൈസ് ചെയ്യുമ്പോഴോ.

Focus Spoofer ഓണായിട്ടും ഹാഷുകൾ മാറാത്തത് എന്തുകൊണ്ട്?

ക്രമീകരണങ്ങളിൽ ഫിംഗർപ്രിന്റ് റാൻഡമൈസേഷൻ ഓഫായിരിക്കാം. ഓണാണെങ്കിൽ ഓരോ പേജ് ലോഡിലും ഹാഷുകൾ മാറും, പുതിയ മൂല്യം കാണാൻ റീലോഡ് ചെയ്യൂ.

എന്റെ ഫലങ്ങൾ എവിടേക്കെങ്കിലും അയയ്ക്കുന്നുണ്ടോ?

ഇല്ല. പരിശോധനകൾ നിങ്ങളുടെ ബ്രൗസറിൽത്തന്നെ നടക്കുന്നു, ലോഗും ഹാഷുകളും ഈ ടാബിൽത്തന്നെ നിൽക്കുന്നു.
