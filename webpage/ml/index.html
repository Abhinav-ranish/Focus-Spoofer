ഇപ്പോഴുള്ള ടാബിൽ ഓൺ ചെയ്യുക, അല്ലെങ്കിൽ ഒരു സൈറ്റ് ഓരോ സന്ദർശനത്തിലും സംരക്ഷിതമാക്കുക. ബാക്കിയെല്ലാം ഒരു ലളിതമായ ക്രമീകരണ പേജിലുണ്ട്.

നേരിട്ടുള്ള മറുപടികൾ

ഇത് ചെയ്യാത്തത്.

പ്രോക്ടറിംഗും ആന്റി-ചീറ്റും മറികടക്കില്ല.

പരീക്ഷാ, ആന്റി-ചീറ്റ് സോഫ്റ്റ്‌വെയറുകൾ ഒരു വെബ് പേജിന് കാണാവുന്നതിലും വളരെയധികം നിരീക്ഷിക്കുന്നു. അവയെ മറികടക്കാൻ ഞങ്ങൾ ശ്രമിക്കുന്നില്ല, അതിനായി ഇതിനെ ആശ്രയിക്കരുത്.

എല്ലായിടത്തും പ്രവർത്തിക്കില്ല.

Chrome, Brave, Edge എന്നിവയിലെ സാധാരണ വെബ് പേജുകളിൽ ഇത് പ്രവർത്തിക്കും. chrome:// പോലുള്ള ബ്രൗസർ പേജുകൾ, Web Store, ബിൽറ്റ്-ഇൻ PDF വ്യൂവർ എന്നിവ ഒരു എക്സ്റ്റൻഷനും ലഭ്യമല്ല.

നിങ്ങളുടെ ബ്രൗസിംഗ് ശേഖരിക്കില്ല.

അക്കൗണ്ടില്ല, ഹിസ്റ്ററിയില്ല, സൈറ്റുകളില്ല. നിങ്ങൾ ഓൺ ചെയ്യാതെ ഉപയോഗ സ്ഥിതിവിവരക്കണക്കുകൾ ഓഫ് ആണ്, ഓൺ ചെയ്താലും ID ഇല്ലാത്ത ദൈനംദിന എണ്ണങ്ങൾ മാത്രം. സ്വകാര്യതാ നയം.

ചോദ്യങ്ങൾ

പതിവായി ചോദിക്കുന്ന ചോദ്യങ്ങൾ.

ഞാൻ ടാബ് മാറിയത് ഒരു വെബ്സൈറ്റ് കണ്ടെത്തുന്നത് എങ്ങനെ തടയാം?

Focus Spoofer ഇൻസ്റ്റാൾ ചെയ്യുക, സൈറ്റ് തുറക്കുക, എക്സ്റ്റൻഷൻ ഐക്കണിൽ ക്ലിക്ക് ചെയ്ത് സ്വിച്ച് ഓൺ ചെയ്യുക. സംരക്ഷണത്തോടെ ടാബ് റീലോഡ് ആകും: document.hidden false ആയി തുടരും, visibilitychange, വിൻഡോ blur ഇവന്റുകൾ ഒരിക്കലും പേജിൽ എത്തില്ല, document.hasFocus() true നൽകും. ഓരോ സന്ദർശനത്തിലും ഒരു സൈറ്റ് സംരക്ഷിക്കാൻ "ഈ സൈറ്റ് എപ്പോഴും സംരക്ഷിക്കുക" ടിക്ക് ചെയ്യുക.

ടാബ് മാറുമ്പോൾ വീഡിയോയോ ക്ലാസോ പോസ് ആകുന്നത് എന്തുകൊണ്ട്?

പല പ്ലേയറുകളും Page Visibility API-യുടെ visibilitychange ഇവന്റോ വിൻഡോ blur ഇവന്റോ ശ്രദ്ധിക്കുകയും ടാബ് മറയുന്ന ഉടൻ പോസ് ആകുകയും ചെയ്യും. ടാബ് പശ്ചാത്തലത്തിലാകുമ്പോൾ ആനിമേഷൻ ഫ്രെയിമുകൾ നിൽക്കുന്നതും ചിലത് ശ്രദ്ധിക്കും. Focus Spoofer ഈ മൂന്നിനും മറുപടി നൽകുന്നു, അതുകൊണ്ട് പ്ലേയർ നിൽക്കാതെ തുടരും.

ടാബ് മാറുമ്പോൾ TikTok, Twitch, കോഴ്സ് വീഡിയോകൾ പോസ് ആകുന്നത് എന്തുകൊണ്ട്?

ഇത്തരം സൈറ്റുകൾ Page Visibility API-യും window blur ഇവന്റും ഉപയോഗിച്ച് അവയുടെ ടാബ് ഇപ്പോഴും ദൃശ്യവും ഫോക്കസിലുമാണോ എന്ന് പരിശോധിക്കുന്നു, അല്ലെങ്കിൽ പ്ലേബാക്ക് പോസ് ചെയ്യുകയോ കുറയ്ക്കുകയോ ചെയ്യുന്നു. ആ ടാബിൽ Focus Spoofer ഓൺ ചെയ്യുക, അല്ലെങ്കിൽ “ഈ സൈറ്റ് എപ്പോഴും സംരക്ഷിക്കുക” ടിക്ക് ചെയ്യുക. അപ്പോൾ പേജ് കാണുന്നത് ദൃശ്യമായ, ഫോക്കസിലുള്ള ഒരു ടാബ് മാത്രം, അതിനാൽ നിങ്ങൾ മറ്റൊരു ടാബിലോ വിൻഡോയിലോ ജോലി ചെയ്യുമ്പോഴും പ്ലേബാക്ക് തുടരും.

Chrome-ൽ Page Visibility API എങ്ങനെ ഡിസേബിൾ ചെയ്യാം?

Chrome-ൽ ഇതിന് ക്രമീകരണമൊന്നുമില്ല. സൈറ്റിന്റെ സ്വന്തം സ്ക്രിപ്റ്റുകൾ പ്രവർത്തിക്കുന്നതിന് മുമ്പ് ഒരു എക്സ്റ്റൻഷൻ പേജിനുള്ളിൽ അതിനെ മറികടക്കണം. Focus Spoofer ഇത് document_start-ൽ, നിങ്ങൾ തിരഞ്ഞെടുക്കുന്ന ടാബുകളിലോ സൈറ്റുകളിലോ മാത്രം ചെയ്യുന്നു, മറ്റ് ടാബുകളെ തൊടുന്നില്ല.

Focus Spoofer സൗജന്യമാണോ, എന്റെ ഡാറ്റ ശേഖരിക്കുമോ?

ഇത് സൗജന്യമാണ്, അക്കൗണ്ട് വേണ്ട. നിങ്ങളുടെ ബ്രൗസിംഗ് ഹിസ്റ്ററിയും സന്ദർശിക്കുന്ന സൈറ്റുകളും പേജ് ഉള്ളടക്കവും ഒരിക്കലും ബ്രൗസറിൽ നിന്ന് പുറത്തുപോകില്ല. ഓപ്ഷണൽ അജ്ഞാത ഉപയോഗ സ്ഥിതിവിവരക്കണക്കുകൾ (ദൈനംദിന എണ്ണങ്ങൾ, ഐഡന്റിഫയർ ഇല്ല) നിങ്ങൾ ഓൺ ചെയ്യുംവരെ ഓഫ് ആണ്. വിശദാംശങ്ങൾ സ്വകാര്യതാ നയത്തിൽ ഉണ്ട്.

ഏതൊക്കെ ബ്രൗസറുകളിൽ ഇത് പ്രവർത്തിക്കും?

Windows, macOS, Linux, ChromeOS എന്നിവയിലെ Chrome, Brave, Microsoft Edge. Chrome Web Store-ൽ നിന്ന് ഇൻസ്റ്റാൾ ചെയ്യുന്ന ഒരു Manifest V3 എക്സ്റ്റൻഷനാണ് ഇത്. Firefox, Safari എന്നിവ പിന്തുണയ്ക്കുന്നില്ല.

ഇത് പ്രവർത്തിക്കുന്നുണ്ടോ എന്ന് എങ്ങനെ പരിശോധിക്കാം?
